# Earth Core：内容圣经（首章）

## 核心命题
Earth Core 并非现实地核，而是被古文明「基岩铸廷」折叠进世界深层法则的囚笼。铸廷曾用四座地脉锚牵引能量、用人工天穹隔离外界；「第一次静默」后，维度失控并分裂为晶化、孢化、熔蚀与玄武岩化生态。玩家不是征服一片无人荒地，而是在一座仍按错误指令运转的文明机器中求生。

## 游戏循环
1. 从传送门抵达余烬前庭，在低压安全带建立补给点。
2. 探索铸廷遗迹，取得译铭片并学会辨识地脉警告。
3. 攻克四个生态域，关闭对应地脉锚；每个区域都有可预警、可缓解的环境威胁。
4. 击败区域 Boss，取得进入下一层的法则抗性，而不是单纯获得钥匙。
5. 四锚沉寂后开启摄政厅，挑战维度首章终局。

## Boss 路线
### 1. 盲井监工
- 场地：环形矿井、三条矿车轨道与可坍塌支柱。
- 机制：Boss 无法直接看见玩家，依据脚步、投射物和矿车声定位；玩家要诱导冲撞支柱破甲。
- 惩罚：错误坍塌会永久缩小本次战斗安全区。
- 解锁：译铭权限，可读取铸廷机关与地脉锚状态。

### 2. 菌冠母体
- 场地：四根维持孢子云的菌柱及有限净化火盆。
- 机制：切断菌柱会降低孢子浓度，但母体会夺取未点燃的火盆再生。
- 惩罚：侵染满值触发幻觉分身；假目标不受场地光照影响，可被识别。
- 解锁：孢囊滤膜，使玩家能够深入高浓度区域。

### 3. 赤潮铸王
- 场地：锻炉、冷却阀与逐步升高的熔岩槽。
- 机制：过热阶段不可硬打；引导攻击击开阀门，再在短暂淬火窗口输出。
- 惩罚：同时误开两阀会引发蒸汽爆发并关闭最近安全平台。
- 解锁：热压隔层，允许进入上层悬穹域。

### 4. 棱镜悼仪者
- 场地：三色晶镜和可旋转反射面。
- 机制：护盾频率随阶段变化，玩家需把对应光束反射回 Boss；错误颜色会强化下一轮弹幕。
- 惩罚：击碎晶镜虽可暂时停火，但会减少终局战的可用反制设施。
- 解锁：棱镜权限，显现摄政厅入口。

### 5. 地脉摄政·空壳
- 第一阶段：调用四锚残余机制，考查此前学到的孢子、热压、声响和反射规则。
- 第二阶段：重构场地，玩家必须在悬穹碎片间迁移并切断能量链。
- 第三阶段：空壳开放核心，但恢复窗口有限；失败的反制会为其恢复护甲而非简单回血。
- 终局奖励：地脉调律能力，为后续章节开放可控的维度改造，而不是直接结束全部内容。

## 难度原则
- 普通战斗目标约为暮色同阶段的两倍压力，但不直接把生命与伤害乘二。
- 每次致命机制至少提供两种预兆：视觉/粒子与声音/动作；高惩罚必须对应清晰反制。
- 环境值必须可衰减、可装备缓解，且创造/旁观/离开维度立即清除。
- Boss 进度采用 advancement 与后续 SavedData 状态；平台模块只负责事件桥接，规则保持在 common。
